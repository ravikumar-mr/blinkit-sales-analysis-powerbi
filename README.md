# Blinkit Sales Analysis – Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **Blinkit Sales Analysis Dashboard** developed using **Microsoft Power BI**. The dashboard analyzes sales performance, outlet characteristics, item categories, customer ratings, and other key business metrics.

## 🎯 Objective

The objective of this project is to transform raw Blinkit sales data into meaningful insights and provide an easy-to-understand view of overall business performance.

## 📌 Key KPIs

* **Total Sales:** $1.20M
* **Average Sales:** $141
* **Number of Items:** 8,523
* **Average Rating:** 3.9

## 📈 Dashboard Analysis

The dashboard includes:

* Total Sales Analysis
* Average Sales Analysis
* Number of Items
* Average Customer Rating
* Sales by Fat Content
* Sales by Item Type
* Sales by Outlet Size
* Sales by Outlet Location
* Outlet Establishment Trend
* Sales by Outlet Type

## 🎛️ Interactive Filters

Users can dynamically analyze the dashboard using:

* Outlet Location Type
* Outlet Size
* Item Type

## 💡 Key Insights

* The dashboard records approximately **$1.20M in total sales**.
* Average sales per item are approximately **$141**.
* The dataset contains **8,523 items**.
* Average customer rating is approximately **3.9**.
* Outlet size, location, item type, and fat content can be compared interactively.
* Outlet establishment trends help identify changes in sales performance over time.

This project demonstrates practical skills in **Power BI, DAX, Power Query, data visualization, dashboard design, and business data analysis**.
